# Examples

All bundled inputs under synthetic/ are generated demonstrations, not manuscript measurements. Regenerate them with `python tools/generate_examples.py`. Numerical expectations and generation parameters are in synthetic/expected.json. No random noise is used.

For publication, additionally supply a small real dataset for each analysis with permission to redistribute, exact settings and trusted reference outputs. Keep real inputs distinct from synthetic ones. The examples alone do not reproduce the PNH manuscript.
